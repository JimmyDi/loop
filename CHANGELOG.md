# Changelog

Notable changes across Agent, coding-agent, and Web UI are recorded here. Pending changes accumulate under Unreleased; release preparation groups them by version and date. See [Contributing](CONTRIBUTING.md#changelog) for the maintenance workflow.

## [Unreleased]

### Added

- Web UI and coding-agent: archive a project's confirmed chat selection without deleting history and persist archive membership independently of conversation saves. Settings → Archived → Archived chats groups history by project with counts, timestamps, project/chat filters and Unarchive actions. Support confirmed deletion of one archived chat, a project's archives or all archives. Preserve drafts on archive and retain archives when re-registering a removed project.
- Web UI: dismiss composer and session error notices, including run cancellation, with a close button while preserving drafts, attachments, validation, session outcomes and save recovery. New errors appear again, and dismissal does not carry over to another session.
- Web UI: show a rotating ring at the right edge of session-list rows during response generation, with live updates for open and background sessions. Keep long titles truncated and respect reduced-motion preferences.
- Web UI: attach UTF-8 text and code files through **Add → Files** or paste, preview or remove them before sending, and retain names and contents in conversation history and uncertain-delivery retries. Show sent files as compact filename pills with visible extensions and expandable contents. Send up to four text files without per-file, combined-text or prompt-body byte caps; reject unsupported formats, binary content and invalid encoding without truncation. Full text enters model context, with provider errors handled through the existing failure flow.
- coding-agent and Web UI: generate durable conversation titles asynchronously from user prompts, with first-user-message fallback names for new and untitled historical sessions, manual renaming, explicit regeneration, and live header/sidebar updates. Empty sessions show New session. Web uses the first prompt; SDK hosts can choose first-prompt or all-prompts generation and a separate model. Failed or stale title requests do not replace accepted titles or affect the main conversation.
- Web UI: add a Settings dialog with General, Models and Appearance tabs under Personal, and Archived chats under Archived. Use regular-weight gray group labels aligned with navigation icons, keyboard navigation and focus restoration.
- Web UI: initialize the interface language from the browser's supported languages and remember manual Chinese or English selections without reloading or interrupting conversations.
- Web UI: add System, Light, and Dark theme previews and persist the selected theme across visits. System follows browser color-scheme changes. Theme styling requires Chrome/Edge 123+, Firefox 120+, or Safari 17.5+.
- Web UI: manage multiple built-in and custom providers with write-only credentials, three custom API protocols, model discovery and editable model metadata. Fetch adds all models from the matching built-in Provider ID catalog or the custom endpoint as editable rows, retaining gateway settings and existing edits. Expand rows to edit capacities or delete models before saving; empty custom model lists remain empty. Start the provider list empty and show only saved providers. Remember model selections for new conversations and preserve readable history when providers are removed.
- coding-agent: expose provider catalog/runtime configuration and optional restoration of history with an unavailable model, while keeping prompt authentication checks.
- Web UI and coding-agent: configure the model and supported reasoning effort from a popover beside Send, listing only saved providers' models under their display names, with search, keyboard controls, session persistence and remembered defaults. Custom models offer effort directly without a capability checkbox; Default sends no explicit reasoning settings.
- Web UI, coding-agent and Agent: send image attachments from the composer using the picker or paste, preview/remove them, preserve them in session history and retain exact images on uncertain delivery. Provider forms no longer require image/reasoning capability switches.

### Changed

- Web UI: expand reasoning sections by default for active turns and collapse completed sections when loading session history, showing only their duration/status header. Keep nested execution timelines expanded when revealed. Show compact tool rows directly without the intermediate call-count accordion, with tighter spacing between rows and action updates, retaining their indentation and a left vertical line shortened at both ends, with a spinner during execution, a green check on success and a red cross on failure. Keep individual tool details collapsed initially and preserve expansion choices through completion and reconnect.
- Web UI and coding-agent: request concise action updates before tool batches and keep each user turn's intermediate updates, thinking and tool batches in one collapsible execution section, with a shared timeline and a separate final answer. Stop the execution icon when reasoning ends without waiting for answer generation; resume it for subsequent reasoning or tools. Show live elapsed work time and failure counts; freeze duration when execution ends and persist it across refresh and history reopening. Expose optional runTimings metadata and run_timing lifecycle events; older sessions retain status labels without inferred durations. Use compact tool rows with adjacent input/output panels and localized action labels when updates are absent. Preserve expanded details during streaming and reconnect, and keep streamed parameters current. Custom system prompts retain their replacement semantics.
- Web UI: replace five-second session-list polling with server-sent list change notifications. Refresh background titles, generation status, projects and archived chats across browser pages when they change; resynchronize lists on reconnect and batch bursts without fetching on each streamed token.
- Web UI: rebalance font sizes with 13px navigation, 14px chat text and input, 12px secondary labels and 18px settings headings. Use a 14px Projects heading with tighter spacing above the first project and 14px No chats placeholders. Keep project and session names at 13px, reduce oversized chat titles and retain 16px mobile input.
- Web UI and coding-agent: highlight session rows on hover and reveal a one-click Archive button. Add a right-click menu with inline Rename, immediate Archive and confirmed Permanently delete. Deletion failures stay inside the confirmation and clear on close or a new action, without leaving an error beneath the session title. Busy-project guidance explicitly includes deletion. Permanent deletion removes the selected chat's history and local drafts, including for unarchived chats; project files remain intact. SessionArchive.delete accepts archivedOnly: false to explicitly include unarchived history while retaining the archived-only default.
- Web UI: group all projects beneath a collapsible Projects heading with a down/right chevron, preserving the selected chat and individual project expansion states. Reveal the heading chevron and Add project button on hover or keyboard focus, keeping them visible on touch devices without shifting the layout. Use open/closed folder icons and a highlighted project row with hover/focus actions. Replace the project + button with a compose pencil and inline Rename/Remove links with a two-item Archive chats/Remove project menu, available through the … button or right-clicking the project row. Both menu items use the same neutral text and icon color. Both actions require confirmation; busy projects and failed requests retain their state.
- Web UI: give the project sidebar a frosted-glass background in Light and Dark themes, with translucent tint, backdrop blur and a soft edge. Use subdued gray for Projects and a softer No chats placeholder. Keep an opaque fallback when blur is unsupported or reduced transparency is requested.
- Web UI: replace routine session status labels above the input with **Looping...** at the end of the conversation during generation, using a left-to-right highlight animation with reduced-motion support. Keep the same label when translation resources are unavailable. Preserve reconnection, error and save-recovery notices.
- Web UI: move attachment upload into a lower-left **+** menu under **Add → Files**, preserving image selection, paste and previews. Align the input text, caret and attachment previews with the visible **+** icon. Change the input placeholder to **Loop anything...** and remove the visible keyboard shortcut hint.
- Web UI: simplify the conversation header to a folder icon matching collapsed project nodes and a session name with tighter spacing and a background matching the conversation. Highlight the name on hover with horizontal text padding and edit it inline with Enter to save and Escape or blur to cancel, synchronizing the header and sidebar. Remove the project path and separate rename/regenerate buttons.
- Web UI: remove the model selector from the session header and place it in the input box.
- Web UI: replace the sidebar language selector with a Settings button. Use a compact rounded hover highlight with narrow side insets, translucent shading and balanced spacing above and below the row.
- Agent and coding-agent: use generic gateway, model, and credential placeholders in usage samples.
- Web UI: move the standalone model configuration entry into Settings → Models. Migrate legacy provider configuration on the next save; model menus show only configured providers. See [provider migration](src/web-ui/backend/docs/providers.md#storage-and-migration).

### Fixed

- Web UI and coding-agent: stream explicitly marked tool updates directly inside reasoning and marked final answers in the answer area without changing indentation. Default instructions request hidden leading display markers; use native text phase metadata when available, and buffer only unclassified text as a fallback. Keep tool rows visible before results with a spinner during execution and success/error icons afterward. Briefly retain the live spinner for fast successes (200ms minimum) so it survives browser paint batching, without delaying tool results, execution or answers; failures and restored history remain immediate. Preserve raw events/history, omit markers from terminal and copied assistant text, and restore streaming placement and tool state on reconnect.
- Web UI: align the reasoning section's left edge and the Looping indicator with the final answer text on desktop and narrow screens.
- Web UI: align tool parameter and result panels to the same height when displayed side by side, preserving independent scrolling and the stacked layout on narrow screens.
- Web UI: match the composer's Send/Stop button right inset to the input text's left inset at 12px, keeping both sides evenly spaced from the border.
- Web UI: remove the blue outline from dialog close buttons, including automatically focused project confirmation dialogs, and use a subtle background highlight for keyboard focus.
- Web UI: keep Archived chats at the same Settings dialog width as General, Models and Appearance, avoiding resizing when switching sections.
- Web UI: align sidebar session titles, inline rename text and No chats placeholders with their project names. Keep project and session names in the same theme-aware foreground color across default, hover, focus and selected states. Give project and session highlights matching widths while retaining text indentation and a narrow gap between adjacent rows. Align the rightmost action buttons across Projects, project and session rows, using consistent icon sizes, spacing and hover styling, with a compact Add project plus glyph.
- Web UI: immediately show and expand the added project, reopen the Projects group and scroll the folder into view. Re-adding a registered folder reveals its existing node without duplication; empty projects show No chats without creating a session.
- Web UI: explicitly serve the Loop infinity favicon for browser tabs and address bars with SVG, PNG and ICO assets. Add Safari Apple touch and pinned-tab mask icons at dedicated URLs, with revalidated routes and conventional icon fallbacks.
- Web UI and coding-agent: keep New session as a draft until the first user message. Do not write empty Web history files or show drafts in the project list; include the conversation as soon as its first user message enters the live run, including attachment-only messages. Hide older unarchived history without user messages without deleting it. Add SessionManager.draft and userMessageCount summaries for this lifecycle.
- Web UI: filter the attachment picker to supported image types and text/code extensions, excluding PDF, PowerPoint and other unsupported formats by default while retaining upload validation.
- Web UI: right-align sent image attachments with the message bubble, removing unused space to the right of image previews.
- Web UI: retain text and code attachments when pasted together with images instead of silently dropping non-image files.
- Web UI: correct the composer model menu chevron to point down when closed and up when open.
- Web UI and coding-agent: retain Pi AI thinking-level mappings for matching custom provider models, exposing supported Extra high and Maximum efforts and passing their mapped values to the configured gateway without changing connection settings.
- Web UI: keep custom provider dialogs within the viewport with only the model list scrolling; connection fields, headers and actions remain fixed while fetching or expanding models.
- Web UI: translate Settings titles, navigation, headings, and descriptions when switching languages. Refresh translations during development hot updates so new strings do not appear as raw keys.

### Removed

- Web UI: remove the Copy button beneath tool results.
- Web UI: remove session tabs, their open/close state and cached titles. Switch conversations through the project sidebar; remember only the selected session across reloads. Preserve drafts, attachments during session switches, saved history and background runs.
