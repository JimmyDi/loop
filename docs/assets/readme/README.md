# README artwork

The root [README](../../../README.md) uses standalone light and dark terminal GIFs.
The terminal follows the page theme, and readers requesting reduced motion receive
a static PNG. The GIFs contain no script
and loop through Web, CLI and SDK examples with typed input and a dust transition;
the leading prompt stays visible. All commands are illustrative and are never run
by the exporter. Copyable startup commands remain in the root README.

The icon, Loop wordmark and two-line tagline form a transparent SVG. All lettering
is outlined with compact path coordinates, so readers do not need the source fonts
installed. The SVG embeds the original 256-pixel PNG icon, avoiding hundreds of
gradient segments while preserving the approved artwork at its 80-pixel size.
Light and dark variants follow the page theme through a `picture` element.
The brand and terminal share one centered paragraph,
using 32% and 66% image widths. No custom CSS or layout table is required.
The terminal also has a transparent outer canvas; its window keeps its own fill.
Badges are SVG images generated by
[Shields.io](https://shields.io/) in the flat style, with green Node.js, blue
TypeScript and gold MIT values. Node.js and TypeScript include their logos.
The first badge links to the project website. Its local SVG variants replace the
label with the Loop icon. Its icon variant and background follow the page theme
through a `picture` element; the Loop value keeps the same indigo fill.
Descriptions, feature lists, startup commands, architecture and documentation links
remain selectable Markdown text.

## Regenerate

Use Python 3 with Pillow installed and supply a local monospaced TTF or OTF font:

```bash
python3 docs/assets/readme/generate.py --mono-font /path/to/monospace.ttf
```

The exporter writes GIF and PNG variants next to itself. No application runtime,
model access or network access is needed. `--theme light|dark|all` limits the export.
The monospaced font is rendered into the artwork, never copied into the repository;
use a font whose license permits this. Exported text metrics depend on the font.

To regenerate the brand, use Node.js 24+ with `skia-canvas` available in the local
tooling environment, and supply a local monospaced TTF or OTF font:

```bash
node docs/assets/readme/generate-brand.mjs /path/to/monospace.ttf
```

This exporter uses the bundled Montserrat font for the wordmark and the supplied
font for the tagline. It writes two 350 × 232 SVGs with outlined text, an embedded
PNG icon and no page background, external resources or font dependencies. Neither
exporter adds an application dependency.

Terminal artwork is 928 × 316 pixels, displayed at 66% of the README content width. The
window itself is 440 × 134 pixels with a small shadow margin. GIF timing uses
40 ms frames, a 1.8-second hold and a
1.7-second dust transition without a blur phase. The palette and particle seed are
fixed to keep repeat exports stable. The static images show the Web command.

GitHub README HTML cannot run a scripted placeholder-to-GIF swap. Instead, the GIF
starts with a complete Web command as a compact poster frame. Browsers that decode
GIFs progressively can display it before the rest of the animation arrives. Only
changed rectangles are encoded after that frame, retaining the transparent outer
canvas and the fixed prompt. This reduces download size without removing the
typing or dust effects. Network and GitHub image-proxy buffering can still delay
the first display; this is not a guaranteed preloaded placeholder.

## Product images and rights

`product-light.webp` and `product-dark.webp` are copies of the reviewed English
1440 × 800 product assets documented in the website's [capture notice](../../../website/public/product/NOTICE.md).
They contain fictional projects, conversations and tool results. They contain no
real sessions or credentials. They are displayed at 720 × 400 pixels on desktop.
Updating website captures does not automatically update these copies.

The original Loop icon assets retain the [brand asset policy](../../../packages/web-ui/src/docs/assets/loop-brand/BRAND-ASSETS.md).
The software's MIT license does not grant rights to the Loop icon.
The Montserrat wordmark outlines retain the font's
[SIL OFL 1.1 notice](../../../website/public/fonts/OFL.txt).

These are GitHub documentation assets; they are excluded from the npm package's
file allowlist. Markdown image paths are relative to the root README, so local and
GitHub previews use the same files.
