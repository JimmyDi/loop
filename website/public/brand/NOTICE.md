# Loop artwork

The Loop artwork in this directory is excluded from the repository's MIT license. All rights in that artwork are reserved to the extent protectable rights exist. These unmodified copies identify the actual Loop project.

The header uses unchanged, manually copied dark and white marks on transparent backgrounds, selected for the light and dark system themes respectively. The favicon retains the primary icon. The website retains its own asset files and does not import application components or styles.

See the retained [brand asset policy](../../../packages/web-ui/src/docs/assets/loop-brand/BRAND-ASSETS.md) for permitted uses. Asset copies are maintained manually; the website does not read application assets at build time or runtime.
