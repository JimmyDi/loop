# Website font

The website uses the unmodified Latin Montserrat variable WOFF2 distributed by [Fontsource Variable Montserrat 5.3.0](https://www.npmjs.com/package/@fontsource-variable/montserrat). The font supports weights 100–900. Marketing headings, body copy, branding and controls use this family outside the capabilities section. Capability copy uses system fonts, and product captures retain native application typography. Chinese glyphs fall back to system Chinese fonts; commands and code retain monospace fonts.

Montserrat is Copyright 2011 The Montserrat Project Authors and licensed under the [SIL Open Font License 1.1](OFL.txt), independently of the repository's MIT license and brand asset policy. Retain this notice and the license with the font.

The font is served locally. No third-party font service is contacted at runtime.
