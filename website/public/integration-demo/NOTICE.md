# MCP and Skills experience captures

These independently maintained 1020 x 684 WebP frames show actual Loop frontend
components with fictional engineering configuration. Website builds never import
application components, capture the frontend or regenerate these assets.

The sequence shows a STDIO Repository Tools server launched by Node with a
repository-relative script, a Streamable HTTP Engineering API Catalog at the reserved
example.com domain, creation of a webhook-review Skill scoped to payments-service,
and its enabled detail view with signature, deduplication and regression checks.
The HTTP form contains an environment variable name, not a token. The command and
service are illustrative configuration, not bundled integrations or verified services.
No commands, connections, discovery, saves, installs, model calls or tasks were run.
No credentials, private endpoints, personal paths or real sessions are included.

Each of stdio, http, skill-create and skill-ready has Chinese/English and Light/Dark
variants. Native product colors, forms, navigation and Skill details are preserved.
Capture-only layout settings fit controls into the frame. Browser chrome, scrollbars
and metadata are excluded. The surrounding capture background is cropped to the
settings window edges consistently across scenes, languages and themes. The website
displays the frames edge to edge without an additional border or letterboxing.
Proportional corner clipping removes captured backing pixels outside the rounded
product window.
Each asset is below 250 KB and was reviewed in October 2026.

The animation plays these frames in order with matching dimensions and timing in
both themes. Native picture sources select each Dark capture or Light fallback from
the live system color scheme without resetting playback. Dark uses the product
theme directly, without recoloring filters.

To update, capture fictional configuration outside website builds, review all language
and theme variants, preserve dimensions and names, hide scrollbars and strip metadata.
