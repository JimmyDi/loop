# Loop product screenshots

These independent 1440 x 800 WebP assets show the actual Loop Web frontend using
fictional engineering projects, conversations and tool results. No model requests or
tools were executed while capturing them. No credentials or real sessions are included.

The storefront-filters scene has Chinese/English and light/dark variants. It shows
commerce-platform, payments-service and design-system with 3, 2 and 4 conversations.
Two additional conversations appear above Projects in Pinned: Review release
readiness and Verify payment idempotency, with translated titles in Chinese.
Non-selected rows display an unread blue dot and a yellow waiting-for-approval
indicator. The composer retains the code-review Skill and an unsent review prompt,
with DeepSeek V4 Pro and High reasoning effort visible. Capture-only layout settings
enlarge body and draft text to 18 pixels, sidebar items and toolbar labels to 16 pixels,
and icons and controls proportionally. A 350-pixel sidebar and a centered 950-pixel
conversation column aligned with the composer keep all content within the unchanged
1440 x 800 canvas. The website display dimensions remain unchanged.
The images are static and exclude browser chrome, backing-surface margins,
scrollbars and capture metadata. Native sidebar, message and composer components are
captured together with fictional data. The model label is fictional demo configuration,
not a verified provider availability claim. They were manually reviewed in October 2026.

To update, capture the actual frontend with fictional business data, review all four
variants, hide scrollbars and remove metadata. Preserve the dimensions and filename
convention, with each image below 250 KB. Do not include personal paths, credentials
or real task data.

Website development, builds and deployment consume these files directly. They never
capture the application or regenerate assets. Product changes do not update the website.
