# Loop product captures

Current Loop workspace with pinned and independent chats, projects, unread/approval indicators, a code-review draft and voice controls.

Captured from the current real Loop frontend components with fictional demo data, reviewed on 2026-10-31. Chinese/English and native Light/Dark variants share scenes and dimensions. No model, application backend, tools, credentials or real sessions were used. Capture tools stay outside website builds. Assets are independent static WebP files with metadata removed, each below 250 KB.

Capture-only layout fits the product controls into the published canvas; screenshots are cropped or letterboxed without recoloring the product theme. Model names are demo configuration, not availability guarantees. Update manually and review every language/theme pair; do not capture real data or personal paths.

The missing sidebar icon was restored in all four language/theme variants using Loop's
existing matching theme PNG, scaled to the frontend's 28px icon size in the original slot.
Pixels outside that slot remain unchanged; files retain no capture metadata.
