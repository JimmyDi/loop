# Loop product captures

Three scenes show model selection, reasoning effort and the ready composer inside a fictional chat. Provider and gateway configuration screens are excluded.

Captured from the current real Loop frontend components with fictional demo data, reviewed on 2026-10-31. Chinese/English and native Light/Dark variants share scenes and dimensions. No model, application backend, tools, credentials or real sessions were used. Capture tools stay outside website builds. Assets are independent static WebP files with metadata removed, each below 250 KB.

Capture-only layout fits the product controls into the published canvas; chat screenshots have top and bottom letterboxing and excess side whitespace removed on the shared 760 × 556 canvas without recoloring the product theme. Model names are demo configuration, not availability guarantees. Update manually and review every language/theme pair; do not capture real data or personal paths.
