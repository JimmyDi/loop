# Provider experience captures

These manually maintained 1000 x 660 WebP frames capture the actual Loop frontend
components with fictional engineering configuration and an unsent catalog API review.
They are independent website assets; website development and builds neither import
the application nor capture or regenerate the frames.

The sequence shows Settings → Models → Add provider with DeepSeek selected,
Add a custom provider with Engineering Gateway, then the chat model menu,
High effort selection and the final DeepSeek V4 Pro composer. The custom gateway
uses the reserved example.com domain. Masked key fields contain only a synthetic
placeholder. The model label and effort choices are demo data, not a verified
provider catalog or availability claim. No credentials, real sessions, model calls,
provider connections, discovery, saves or prompt execution are included.

Chinese/English and light/dark variants share the five business-oriented frame names:
builtin, custom, model, effort and ready. Native form, navigation, composer and menu
styles are preserved. Capture-only positions place the settings dialogs within the
frame; the chat content is cropped and centered without distorting its typography.
The surrounding capture background is cropped to the settings window edges, using
the same crop across scenes, languages and themes. The website displays the frames
edge to edge without an additional border or letterboxing. Proportional corner
clipping removes captured backing pixels outside the rounded product window.
Browser chrome, scrollbars and image metadata are excluded. All frames were reviewed
locally in October 2026 and each is below 250 KB.

Every frame uses a native picture source for the Dark capture and a Light fallback.
The browser selects the matching asset for its live system color scheme, including
when the theme changes during playback; the current frame and playback timing stay
unchanged. Dark captures use the actual product theme, without image filters.

To update, capture the real components with fictional data separately from website
builds, review every language/theme variant, preserve the frame dimensions and
filename convention, hide scrollbars and strip metadata. Never include personal
paths, credentials, private endpoints or real task data.
